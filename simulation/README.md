# Capillary electrical paired-input study

This offline simulation evaluates whether paired capillary inputs distinguish a distributed Kir membrane mechanism from simpler electrical mechanisms after calibration restricted to single-input behavior. The published single-input amplitude and reversibility screen evaluates two explicit broad-exposure footprints at the reported stimulus duration; the exposure cell count is a structural assumption. This screen is distinct from the synthetic trace fitting used to compare model classes. Neither is an external validation of paired predictions.

Run from this directory with `uv sync --frozen` and `uv run python run_all.py`. The main runner executes the required pytest suite, writes `output/tests.xml` and `output/tests.log`, and fails on failures, errors, skipped tests, or an empty suite. `uv run pytest -q` also runs the tests separately. The collection's `papers run integration-in-the-capillary-bed --id paired-study --cwd simulation --artifact simulation/output/results.json --input simulation/data/parameters.json -- uv run python run_all.py` records execution and artifact hashes. Run `uv lock` before recording. All stochastic sampling has a fixed seed. The analysis downloads nothing. Declare `simulation/data/parameters.json` as the frozen numerical input; registry/full-text source evidence has a separate provenance manifest and is not fetched by the analysis. Include the result JSON, calibration NPZ, test XML/log, and generated figure PDFs/PNGs as recorded artifacts when using the collection tooling.

`capnet/model.py` contains the inherited ionic equations and implicit gap-junction solver, audited against Moshkforoush and colleagues' published model code. `capnet/network.py` defines idealized symmetric trees and an anastomosis. The geometries are design assumptions, not reconstructed vascular specimens. `capnet/experiment.py` defines all stimulation, ablations, the fixed diameter/flow proxy, and residual decomposition. `run_all.py` performs screening, fitting, uncertainty calculations, held-out prediction, experiment selection, and figure generation.

The membrane units are pF, mV, nS, pA and ms. The capillary Kir conductance is normalized at resting extracellular potassium; the published maximum Kir coefficient instead has units nS per square-root mM. These two parameterizations differ by the square root of resting potassium. Gap resistance is in MOhm and its reciprocal is multiplied by one thousand to obtain nS. The coupled endothelial/smooth-muscle arteriolar units are assumed equipotential within each lumped axial node.

The distributed model has three fitted parameters: capillary Kir conductance, capillary background conductance, and capillary gap-junction resistance. All others are fixed, with source identity and epistemic status in `data/parameters.json`. The basal current and positive membrane tangent are preserved in linearized membranes. A small positive slope floor ensures that a nominally passive control does not retain negative-resistance gain. Potassium-sensitive current in a linearized input cell is evaluated at its resting voltage. The distal-active localization ablation retains nonlinear Kir throughout the distal branches while linearizing the unstimulated common capillary trunk. Its fixed architecture is distinct from the independent-sensor oracle.

A connected broad exposure patch is used for the published single-input screen; a smaller connected patch tests sensitivity to its assumed cell count. Each mechanistic rival is refitted with the same free-parameter bounds and single-input objective. The pooled dynamic filter has three fitted coefficients and is driven by a fixed passive cable using predeclared published-model values. Its passive driver is not calibrated to the nominal distributed model. It can produce supra-additive or subadditive voltage through a quadratic pooled drive and a temporal state. The independent-sensor oracle is stronger than an ordinary fit: it receives every exact isolated single-input waveform, including on held-out topologies, and sums them without feedback. These additional singleton traces are used to define paired residuals and the oracle, never to refit the mechanistic rivals.

The central observable is the difference between the electrical interaction residual for sibling terminal inputs and that for distant equal-depth inputs. A pooled controller driven by the identical summed single-input waveform has identical outputs for these geometries, regardless of its nonlinear dynamics. Local sensor loading and distributed membrane regeneration can both break that invariance. The reported nearest-rival separation therefore includes the distal-active and refitted ablation controls.

The common output map transforms positive arteriolar hyperpolarization into a saturating relative diameter, then uses a constant-pressure fourth-power flow proxy. Its constants are declared assumptions, shared by every model. The electrical residual is calculated before this transform. The separate output-transform contribution includes both the convex fourth power and diameter saturation; it need not be negative.

Precision calculations concern a prespecified scalar contrast and independent condition means, with a normal approximation. They do not convert repeated imaging frames into independent biological replicates. Parameter envelopes are finite sampled sets and local tolerance sets, not posterior probabilities or confidence intervals. Focal Kir block is an idealized selective perturbation of unstimulated capillary trunk nodes. Its actual spatial selectivity and effects on other cell classes require experimental controls. The KATP scenario is an assumed effective capillary-node conductance and contains no explicit pericyte compartment or metabolic feedback.

`tests/` checks ionic reversal and signs, electrical conservation, graph symmetry, the implicit solver against a direct solve, superposition, batch consistency, baseline stationarity, and exact output-residual decomposition. Numerical refinement in `results.json` evaluates the experiment's contrast as well as individual traces. The final figures are generated under `paper/figures/` and are sized for print.

`fetch_sources.py` is separate from the offline analysis. The source archive contains registry responses and inspected publication/model material with provenance; no experimental subject-level measurements are supplied as an analysis dataset. Published descriptive values used as screening constraints retain their limitations in the parameter provenance record. Numerical outputs in `output/` become manuscript evidence only after a recorded execution.
